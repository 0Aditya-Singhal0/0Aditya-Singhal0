# Aditya Singhal

AI systems engineer working across applied machine learning, backend systems, deployment infrastructure, computer vision, and autonomous systems.

I build software that connects models to APIs, services, data, users, and hardware. My work covers inference pipelines, multimodal applications, AI infrastructure, and research in robotics and control.

## Current work and interests

- Applied AI and machine learning systems
- Generative AI and multimodal applications
- Backend architecture, APIs, and distributed services
- Deployment systems, queues, containers, and cloud infrastructure
- Computer vision and real-time inference
- Robotics, reinforcement learning, trajectory planning, and control

## Selected projects

### [AI trainer](https://github.com/0Aditya-Singhal0/AI_trainer)

A computer-vision fitness system for exercise recognition, repetition counting, and form analysis. The repository combines pose estimation, sequence modeling, biomechanical comparison, FastAPI, and Docker.

### [Comfy Runner](https://github.com/0Aditya-Singhal0/comfy_runner)

Backend tooling for running ComfyUI workflows. It handles workflow setup, model and custom-node installation, execution, and output management.

### [TD3PG obstacle avoidance simulator](https://github.com/0Aditya-Singhal0/TD3PG_Obstacle_Avoidance_Sim)

A simulation project for testing deep reinforcement learning approaches to robotic obstacle avoidance.

### [MoveIt with GPD](https://github.com/0Aditya-Singhal0/moveit_with_GPD)

Robotics work combining MoveIt and grasp-pose detection in a ROS-based workflow.
